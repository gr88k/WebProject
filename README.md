**Для запуска фронтенда: python -m http.server 3000**

**Для запуска бэкенда: docker-compose up --build -d**

**Доступ по: http://localhost:3000**

**Тесты на бэкенд работают через docker**

**Критерии по фронтенду:**

*Регистрация*
*Страница отправки и просмотра сообщений*
*Лента публикаций и событий*
*Форма создания новости или мероприятия*
*Страница создания группы*
*Страница просмотра группы*
*Форма создания публикации*
*Комментарии и оценки публикаций*
*Валидация форм*
*Обработка серверных ошибок*
*Unit- и интеграционные тесты*

**Критерии по бэкенду:**

*Авторизация*
*Ролевая система доступа*
*CRUD-операции для всех сущностей*
*Хранение данных в БД*
*Контейнеризация*
*Использование инструмента для миграций*
*Валидация входных данных и обработка ошибок*
*Фильтрация и поиск данных*
*Unit- и интеграционные тесты*
